# Data Loom

FastAPI が画面を配信する、local-first の JSONL 編集アプリです。JSONL 本体はサーバーへ送信せず、ブラウザの Worker で処理します。

## 起動

Python 3.12 以上、uv、Node.js 22 以上と npm を使用します。

```bash
uv venv
uv sync
npm --prefix frontend ci
npm --prefix frontend run build
uv run data-loom --port 8765
```

PC 版 Chrome または Edge で <http://127.0.0.1:8765> を開きます。外部へ配置する場合は HTTPS が必要です。フロントエンド開発時は `npm --prefix frontend run dev` を使用できます。開発サーバーは127.0.0.1に限定します。

Python ライブラリは `.venv/`、JavaScript ライブラリは `frontend/node_modules/` に入ります。Node.js 自体は npm と別管理です。依存パッケージのグローバルインストールは不要です。

本番ビルドには Geist と IBM Plex Mono のローカル Web フォントが含まれます。フォントの著作権表示と SIL Open Font License 1.1 は [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) に収録しています。

## 使い方

- **開く・結合**：複数ファイルを選び、順序を変更して開きます。ファイルごとの行順は保持します。
- **編集**：左の行一覧で選び、KEY 別の枠で編集し「変更を確定」。文字列・数値・真偽値・null を区別します。配列・オブジェクトは表に件数と「開く」ボタンで表示し、押すと中身の表へ切り替わります。上部の経路（行 > aaa > bbb）を押すと上の階層へ戻ります。どの階層で「変更を確定」しても行全体を保存します。
- **枠の大きさ**：短い値と配列・オブジェクトは左の表、長文は右の詳細欄に表示します。配列・オブジェクトの配置を「右の詳細」か「全幅」にすると、JSON として直接編集できます。各 KEY の右上の設定で「左の表／右の詳細／全幅」と高さを変更できます。テキスト欄の右下をドラッグして高さも変更できます。手動設定は同じ KEY の全行と次回の作業再開に適用します。自動配置は確定済みの値に合わせます。入力中は項目の位置を維持し、画面が狭い場合は上下に並べます。旧版のサイズ設定には自動・手動の区別がないため、この更新時には再計算されます。
- **ピン留め**：各 KEY のピンを押すと、表・右の詳細ではそのグループの先頭、全幅では左右の列より上に表示します。複数のピンは元の KEY 順で並び、解除で元の位置へ戻ります。設定は作業とともに保存します。
- **検索・抽出**：全文の文字列、最上位 KEY の部分一致・等値・存在・型を AND 条件で検索します。KEY は読み込み時に見つかった候補から選ぶか、手入力できます。候補にない KEY も手入力で指定できます。等値の文字列は `"train"`、数値は `123`、存在は `true` / `false`、型は `string` / `number` / `boolean` / `null` / `array` / `object` を指定します。
- **KEY 操作**：現在行・全件・抽出結果への追加、削除、改名。事前確認後に適用します。衝突時は上書きせず中止します。
- **行操作**：追加・複製・削除、Undo／Redo。追加行と複製行は末尾に置きます。新たな編集を開始すると Redo の枝は破棄します。
- **検証**：不正 JSON、空行、重複 KEY、UTF-8 エラー、オブジェクト以外、容量上限を超える行を抽出します。件数バッジは元ファイルの診断件数です。検索された一覧は現在の編集・削除状態を反映します。
- **書き出し**：全件または抽出した行を、別の JSONL ファイルへ保存します。行数・ファイル数・目標バイト数で分割できます。分割先に同名のファイルがあれば停止します。

保存先の選択はブラウザ標準のダイアログです。分割では保存フォルダへの書き込み権限が必要です。分割ファイル名は `dataset-0001.jsonl` のようになります。

全文検索はメイン画面の検索欄に入力して Enter または「検索」で実行します。この操作では KEY 条件を解除して全文のみを検索します。「条件で抽出」では KEY の候補選択と手入力を1つの入力欄で行えます。全文検索欄に文字列がある場合は、KEY 条件と組み合わせて抽出します。

## データの保管と制限

| データ | 保存場所 |
| --- | --- |
| 元の JSONL | 選択した端末上のファイル。読み取り専用で利用 |
| 行索引・検索結果索引 | ブラウザの OPFS。行あたり24バイト、抽出行あたり8バイト |
| 編集差分・Undo履歴・枠サイズ・元ファイル参照 | ブラウザの IndexedDB |
| 完成した JSONL | 指定した別ファイル／フォルダ |

UTF-8 の1行1オブジェクトが対象です。BOM、LF／CRLF、末尾改行なしに対応し、編集する数値の精度を維持します。未編集行は元のバイト列を使用します。ただし結合途中の BOM は除去し、改行がない行末に LF を補います。不正行は書き出し時に「中止／保持／除外」を選択します。1行16 MiBを超える場合は解析・編集・通常検索を行わず、未検証の元データとして保持して出力できます。容量分割の指定を単独で超える行は1ファイルにします。

1〜5 GiB を検証対象としています。ファイル全体を文字列・配列・Blob にまとめず、1 MiB 単位の読取と書込、ディスク索引、表示行だけの取得を使います。単一の編集可能な行には最大16 MiBが必要で、解析後のオブジェクトや表示には追加のメモリを使います。ディスク容量・端末性能に応じた限界はあります。

「保存した作業」から再開できます。ファイルアクセスを再許可する場合があります。「通常のファイル選択」で開いた作業は、元のファイルを同じ順序で選び直します。サイズ・更新日時・SHA-256 が一致した場合だけ差分を適用します。元ファイルを移動・削除・変更すると復元できない場合があります。読み込み中に中止した作業は再開できないため、新しく開き直してください。

ブラウザのサイトデータは作業用領域です。データ削除やブラウザによる消去で差分も失われます。大切な成果は JSONL に書き出してください。ポート・ホスト・ブラウザプロファイルが変わると別の保存領域になります。同じ作業を複数タブで同時に編集することはできません。

作業を消すときは「保存した作業」から削除します。元ファイルと書き出し済みファイルは残ります。容量不足・権限拒否・中止では確定済み差分を維持します。途中まで完了した分割ファイルは残るため、通知の完了済みファイル名を確認してください。

## 検証

実画面検証スクリプトと手順は [tools/README.md](tools/README.md) にあります。Playwright は常に **headless=False** で、実際の画面にブラウザを表示します。仮想ディスプレイやバックエンドのテストだけで画面検証を代替しません。

```bash
npm --prefix frontend test
uv run pytest src/data_loom/web/tests
uv run python tools/verify_ui.py --native-dialogs
```

実行結果と計測上の制限は [docs/VERIFICATION.md](docs/VERIFICATION.md)、構成は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) を参照してください。
